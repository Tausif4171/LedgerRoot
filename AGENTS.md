# LedgerRoot implementation rules

Independent prototype, not an Ambrook integration or a validated missing feature. Never invent evaluation results or relabel authored fixtures as real AI output.

- Preserve the original document, model outputs, and human revisions separately.
- No automatic approval, accounting posting, or inline processing fallback.
- Enforce validation, authorization, idempotency, and revision checks on the server.
- Keep browser-safe contracts and pure domain rules separate from infrastructure.
- Use the six base design tokens; maintain keyboard access, reduced motion, and responsive reflow.
- Read any later-installed frontend-design, ui-ux-pro-max, and web-design-guidelines skills before claiming their use. They are not currently installed.
- Keep changes within this repository; never copy proprietary MinIO source.
- Run lint, typecheck, unit tests, integration tests, browser/accessibility tests, and build. Record checks that could not run honestly.
